# PECVD设备

## 概述与原理
- 技术描述：等离子体增强化学气相沉积（PECVD）设备是光伏电池制造中的核心工艺设备，用于在硅片表面沉积氮化硅（SiNx）减反射/钝化膜、非晶硅薄膜等。PECVD技术利用等离子体激活反应气体，在低温下实现薄膜沉积，是PERC、TOPCon、HJT等电池技术的关键设备。
- 工作原理：在真空腔室中通入硅烷（SiH4）和氨气（NH3）等反应气体，通过射频/微波电源产生等离子体，将气体分子电离激活为活性基团。这些活性基团在硅片表面发生化学反应，沉积形成氮化硅薄膜，同时氢原子扩散进入硅体钝化缺陷。
- 所属类别：光伏制造设备
