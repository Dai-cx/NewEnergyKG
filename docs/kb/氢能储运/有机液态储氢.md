# 有机液态储氢

## 概述与原理
- 技术描述：有机液态储氢（LOHC）是一种利用不饱和有机液体化合物（如二苄基甲苯、N-乙基咔唑）通过催化加氢和脱氢反应实现氢气储存和释放的技术。氢气以化学键形式储存在有机液体中，可利用现有石油储运基础设施，是氢气大规模储运的重要方向。
- 工作原理：储氢时，氢气与不饱和有机载体（如二苄基甲苯）在催化剂作用下发生加氢反应，生成饱和化合物。释氢时，饱和化合物在催化剂作用下加热脱氢，释放氢气并恢复为不饱和载体。载体可循环使用。
- 所属类别：氢能储运

## 优缺点与效率
- 优点：可利用现有石油储运基础设施
- 优点：常温常压储存，安全性高
- 优点：储氢密度较高
- 优点：适合大规模长距离运输
- 优点：载体可循环使用
- 优点：与化石能源供应链兼容
- 缺点：脱氢能耗高（约20-30%）

- 缺点：载体成本较高
