# 固态储氢

## 概述与原理
- 技术描述：固态储氢是利用金属氢化物、配位氢化物或碳纳米材料等固态材料吸附或化学反应储存氢气的技术。氢气以原子态或离子态储存在材料晶格中，具有储氢密度高、安全性好、无需高压或低温等优势，是极具潜力的新型储氢方式。
- 工作原理：氢气分子在金属表面解离为氢原子，氢原子扩散进入金属晶格间隙形成金属氢化物（如LaNi₅H₆、MgH₂、TiFeH）。储氢时放热，释氢时吸热。通过调节温度和压力控制吸放氢过程。
- 所属类别：氢能储运

## 优缺点与效率
- 优点：储氢密度高（体积密度优于液氢）
- 优点：安全性极高，无高压风险
- 优点：无需低温或高压
- 优点：氢气纯度高
- 优点：可小型化
- 优点：适合车载和分布式应用
- 缺点：储氢材料重量大（储氢质量比低）
- 缺点：吸放氢动力学较慢
- 缺点：材料成本高
- 缺点：部分材料易粉化
- 缺点：热管理复杂
- 缺点：循环寿命待提升
- 效率：储氢质量比1.5-7.6wt%，体积密度优于液氢
