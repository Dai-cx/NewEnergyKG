# 低温液态储氢

## 概述与原理
- 技术描述：低温液态储氢是将氢气冷却至-253℃（20K）使其液化后进行储存的技术。液氢密度是气态氢的845倍，储氢密度高，适合大规模长距离运输和航天应用。但液化能耗极高（约30-40%），且需要严格的绝热措施，成本较高。
- 工作原理：氢气经过多级压缩和预冷后，通过膨胀机或焦耳-汤姆逊阀绝热膨胀降温至-253℃以下，氢气液化。液氢储存在高真空多层绝热储罐中，通过真空隔热层和反射屏最大限度减少热辐射传入，维持低温状态。
- 所属类别：氢能储运
