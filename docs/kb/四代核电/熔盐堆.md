# 熔盐堆

## 概述与原理
- 技术描述：熔盐堆（MSR）是一种以熔融氟化盐作为冷却剂和燃料载体的第四代核反应堆。熔盐既是冷却剂又是燃料载体（液态燃料），可在高温低压下运行，具有固有安全性、燃料循环灵活、可在线后处理等优势。中国钍基熔盐堆（TMSR）研究处于世界前列。
- 工作原理：核燃料（铀或钍的氟化物）溶解在熔融氟化盐（如LiF-BeF₂）中作为燃料盐，在堆芯中发生裂变反应。熔盐同时作为冷却剂，将热量带出堆芯至热交换器，产生蒸汽发电。负温度系数确保固有安全，熔盐凝固可自动停堆。
- 所属类别：四代核电
