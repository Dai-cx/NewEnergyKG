# 小型模块化反应堆

## 概述与原理
- 技术描述：小型模块化反应堆（SMR）是一种功率通常在10-300MW、采用模块化设计可在工厂预制后运输到现场组装的小型核反应堆。具有建设周期短、投资规模小、选址灵活、可逐步扩容、安全性高等优势，适合偏远地区、工业园区、海岛供电和核能供热等场景。
- 工作原理：采用成熟压水堆、高温气冷堆或熔盐堆技术，将反应堆功率缩小至10-300MW。关键设备和模块在工厂预制，运输到现场组装。可采用非能动安全设计，实现固有安全。多个模块可并联运行，逐步扩容。
- 所属类别：四代核电
