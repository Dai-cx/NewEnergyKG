# 高温气冷堆

## 概述与原理
- 技术描述：高温气冷堆（HTGR）是一种采用氦气作为冷却剂、石墨作为慢化剂的第四代先进核反应堆。出口温度可达750-950℃，具有固有安全性（负温度系数、衰变热自然排出），可用于高效发电、核能制氢和工业供热。中国石岛湾200MW高温气冷堆示范工程是全球首座球床模块式高温气冷堆核电站。
- 工作原理：采用全陶瓷包覆颗粒燃料（TRISO），燃料颗粒弥散在石墨球中。氦气作为冷却剂在堆芯加热至750-950℃，通过蒸汽发生器产生蒸汽发电，或直接驱动氦气轮机发电。负温度系数确保反应性自调节，衰变热可通过自然对流和热辐射安全排出。
- 所属类别：四代核电
