# 钠冷快堆

## 概述与原理
- 技术描述：钠冷快堆（SFR）是一种采用液态金属钠作为冷却剂、快中子谱运行的第四代核反应堆。快堆可将铀-238转化为钚-239，实现核燃料的增殖和闭式燃料循环，大幅提高铀资源利用率（60-70倍）。中国实验快堆（CEFR）已运行，示范快堆建设中。
- 工作原理：采用快中子谱（无慢化剂），以高浓度铀或混合氧化物（MOX）燃料。液态钠作为冷却剂，具有优异的热传导性能。快中子被铀-238吸收后转化为钚-239，实现核燃料增殖。一回路钠将热量传递给二回路钠，再通过蒸汽发生器产生蒸汽发电。
- 所属类别：四代核电
