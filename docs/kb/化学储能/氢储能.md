# 氢储能

## 概述与原理
- 技术描述：氢储能是一种利用电能将水电解为氢气储存，在需要时通过燃料电池或氢气轮机将氢能转化为电能的储能技术。具有储能容量大、储能时间长、可跨季节存储等优势，是实现大规模可再生能源消纳和季节性调峰的重要技术路径。
- 工作原理：储能阶段，利用富余电力通过电解水装置将水分解为氢气和氧气，氢气经压缩或液化后储存。释能阶段，氢气通过燃料电池电化学反应发电，或通过氢气轮机燃烧发电。也可直接作为工业原料或交通燃料。
- 所属类别：化学储能

## 优缺点与效率
- 优点：储能容量极大，可跨季节存储
- 优点：储能时间长（数周至数月）
- 优点：氢气可多元利用（发电/交通/工业）
- 优点：环境友好，产物仅为水
- 优点：可长距离运输
- 优点：与可再生能源高度协同
- 缺点：往返效率低（约30-40%）
- 缺点：电解水成本高
- 缺点：氢气储运难度大
- 缺点：燃料电池成本高
- 缺点：基础设施建设滞后
- 缺点：安全性要求高
- 效率：电解效率60-70%，燃料电池效率50-60%，往返效率约30-40%
- 成熟度：产业化初期
- 发展阶段：示范应用
