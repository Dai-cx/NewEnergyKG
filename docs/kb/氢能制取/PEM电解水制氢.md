# PEM电解水制氢

## 概述与原理
- 技术描述：质子交换膜电解水制氢（PEM）是一种采用固体聚合物电解质膜将水电解为氢气和氧气的先进制氢技术。与碱性电解相比，PEM电解具有响应速度快、效率高、产出氢气纯度高、结构紧凑等优势，特别适合与波动性可再生能源（风电/光伏）耦合制氢。
- 工作原理：水从阳极侧进入，在阳极催化剂作用下分解为氧气、质子和电子（2H₂O→O₂+4H⁺+4e⁻）。质子通过质子交换膜迁移至阴极，与电子结合生成氢气（4H⁺+4e⁻→2H₂）。全氟磺酸膜（如Nafion）作为固体电解质，无需液态碱性溶液。
- 所属类别：氢能制取
