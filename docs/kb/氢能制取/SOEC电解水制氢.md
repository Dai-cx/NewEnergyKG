# SOEC电解水制氢

## 概述与原理
- 技术描述：固体氧化物电解水制氢（SOEC）是一种在高温（700-900℃）下运行的先进电解技术，利用固体氧化物陶瓷作为电解质。SOEC具有极高的电解效率（可达90%），且可共电解CO₂和H₂O生成合成气，是高效制氢和碳利用的前沿技术。
- 工作原理：在高温下，水蒸气在阴极被还原生成氢气和氧离子（H₂O+2e⁻→H₂+O²⁻）。氧离子通过固体氧化物电解质（如YSZ氧化钇稳定氧化锆）迁移至阳极，在阳极被氧化生成氧气（O²⁻→1/2O₂+2e⁻）。高温降低电解电压，大幅提升效率。
- 所属类别：氢能制取
