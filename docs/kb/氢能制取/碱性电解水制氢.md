# 碱性电解水制氢

## 概述与原理
- 技术描述：碱性电解水制氢（ALK）是一种利用碱性电解质（通常为氢氧化钾溶液）将水电解为氢气和氧气的成熟制氢技术。该技术已有百年历史，设备成本低、寿命长，是目前最主流的大规模绿氢生产方式，单台设备容量可达1000Nm³/h以上。
- 工作原理：在直流电作用下，水分子在阴极被还原生成氢气和氢氧根离子（2H₂O+2e⁻→H₂+2OH⁻），氢氧根离子通过隔膜迁移至阳极，在阳极被氧化生成氧气和水（4OH⁻→O₂+2H₂O+4e⁻）。使用石棉或复合隔膜分隔两极，防止氢氧混合。
- 所属类别：氢能制取
