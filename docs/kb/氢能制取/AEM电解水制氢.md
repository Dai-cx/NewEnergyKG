# AEM电解水制氢

## 概述与原理
- 技术描述：阴离子交换膜电解水制氢（AEM）是一种介于碱性和PEM之间的第三代电解技术，使用阴离子交换膜作为固体电解质，允许氢氧根离子通过。AEM电解兼具碱性电解的低成本优势和PEM电解的高效率优势，且可使用非贵金属催化剂，是近年来备受关注的新兴技术。
- 工作原理：水在阴极被还原生成氢气和氢氧根离子（2H₂O+2e⁻→H₂+2OH⁻），氢氧根离子通过阴离子交换膜迁移至阳极，在阳极被氧化生成氧气和水（4OH⁻→O₂+2H₂O+4e⁻）。阴离子交换膜替代了碱性电解中的液态电解质和石棉隔膜。
- 所属类别：氢能制取
