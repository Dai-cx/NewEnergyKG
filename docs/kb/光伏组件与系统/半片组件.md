# 半片组件

## 概述与原理
- 技术描述：半片组件是一种将标准电池片沿垂直于主栅方向切割成两半，再通过串联-并联方式连接的新型光伏组件。通过降低电池片工作电流，减少电阻损耗和隐裂风险，提升组件功率和可靠性。
- 工作原理：将整片电池激光切割为两个半片，每半片电流减半。在组件内部采用先串联后并联的电路设计，总电流为半片电流的两倍，但单片电流降低50%，显著减少串联电阻引起的功率损耗（P=I2R）。
- 所属类别：光伏组件与系统
