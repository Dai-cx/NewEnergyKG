# 光伏逆变器

## 概述与原理
- 技术描述：光伏逆变器是光伏发电系统的核心电力电子设备，负责将光伏组件产生的直流电（DC）转换为符合电网要求的交流电（AC）。现代逆变器还集成最大功率点跟踪（MPPT）、电网保护、数据监控等功能，是光伏系统的大脑。
- 工作原理：通过电力电子开关器件（IGBT/SiC MOSFET）的高频开关，将直流电斩波为高频交流脉冲，再经滤波器平滑为工频正弦交流电。同时通过MPPT算法实时调节工作点，使光伏阵列始终输出最大功率。
- 所属类别：光伏组件与系统
