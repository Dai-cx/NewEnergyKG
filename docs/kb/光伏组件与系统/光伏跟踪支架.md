# 光伏跟踪支架

## 概述与原理
- 技术描述：光伏跟踪支架是一种能够根据太阳位置自动调整光伏组件角度的支撑系统，通过实时追踪太阳轨迹，使组件始终垂直于入射光线，较固定支架可提升10-25%发电量。主要分为单轴跟踪和双轴跟踪两种类型。
- 工作原理：通过天文算法或光传感器计算太阳实时位置，驱动电机带动支架旋转，使组件平面法线与太阳光线夹角最小化。单轴跟踪仅调整方位角，双轴跟踪同时调整方位角和高度角。
