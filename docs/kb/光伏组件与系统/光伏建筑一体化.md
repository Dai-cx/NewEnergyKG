# 光伏建筑一体化

## 概述与原理
- 技术描述：光伏建筑一体化（BIPV）是将光伏发电系统与建筑物同时设计、同时施工、同时安装，使光伏组件成为建筑结构的一部分（如屋顶、幕墙、遮阳板等），兼具发电和建筑功能，是建筑领域实现碳中和的关键技术。
- 工作原理：将光伏组件替代传统建筑材料（玻璃幕墙、屋顶瓦片、遮阳板等），组件既作为建筑外围护结构发挥防水、隔热、采光等功能，又通过光电效应将太阳能转换为电能，实现建筑从能源消耗者向生产者的转变。
- 所属类别：光伏组件与系统

## 优缺点与效率
- 优点：节省建筑材料成本
- 优点：发电与建筑功能合一
- 优点：美观性好，可定制化设计
- 优点：降低建筑能耗
- 优点：提升建筑绿色评级
- 优点：可利用建筑大面积表面
- 缺点：初始投资高于传统BAPV
- 缺点：建筑设计复杂度高
- 缺点：组件更换困难
- 缺点：需考虑建筑规范和消防要求
- 缺点：发电效率略低于标准组件
- 缺点：维护不便
- 效率：发电效率略低于标准组件（约15-20%），但综合建筑价值高
