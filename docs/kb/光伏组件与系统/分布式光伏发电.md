# 分布式光伏发电

## 概述与原理
- 技术描述：分布式光伏发电是指在用户所在场地或附近建设运行，以用户侧自发自用为主、多余电量上网的光伏发电设施。主要包括工商业屋顶光伏、户用光伏、光伏建筑一体化等形式，具有就地消纳、减少输配电损耗、灵活部署等优势。
- 工作原理：在用户侧（屋顶、墙面、车棚等）安装光伏组件，通过逆变器将直流电转为交流电，优先供给本地负载使用，多余电量通过并网逆变器送入公共电网，不足部分从电网补充。可配置储能实现更高自给率。
- 所属类别：光伏组件与系统

## 优缺点与效率
- 优点：就地消纳，减少输配电损耗
- 优点：节省电费支出
- 优点：可利用闲置屋顶资源
- 优点：安装灵活，规模可大可小
- 优点：缓解电网峰荷压力
- 优点：投资回收期短（5-8年）
- 缺点：受屋顶面积和朝向限制
- 缺点：发电量波动大，需电网平衡
- 缺点：初始投资需用户承担
- 缺点：并网手续复杂
- 缺点：对电网稳定性有一定影响
- 缺点：储能配套增加成本

- 成熟度：成熟
