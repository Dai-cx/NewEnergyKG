# 双面光伏组件

## 概述与原理
- 技术描述：双面光伏组件是一种正面和背面均可吸收太阳光发电的光伏组件。通过使用透明背板或玻璃代替传统不透明背板，利用地面反射光和散射光，可提升5-30%的发电量，是降低度电成本的有效技术路径。
- 工作原理：组件正面直接接收直射太阳光，背面接收经地面、水面、雪地等反射的散射光。双面率（背面/正面功率比）通常在70-90%。总发电量=正面发电量+背面发电量*双面率*反射率增益。
- 所属类别：光伏组件与系统

## 优缺点与效率
- 优点：可提升5-30%发电量

- 优点：质保期与单面组件相同
