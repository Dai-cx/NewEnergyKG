# 三元锂电池

## 概述与原理
- 技术描述：三元锂电池是指正极材料使用镍钴锰酸锂或镍钴铝酸锂的锂离子电池。其能量密度高，但安全性和成本相对磷酸铁锂电池略逊。
- 工作原理：与磷酸铁锂电池类似，通过锂离子在层状氧化物正极和石墨负极之间的嵌入/脱嵌实现电化学反应。
