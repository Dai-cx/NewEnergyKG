# 磷酸铁锂电池

## 概述与原理
- 技术描述：磷酸铁锂电池是一种使用磷酸铁锂作为正极材料，碳作为负极材料的锂离子电池。其具有安全性高、循环寿命长、高温性能好、成本较低等优点，但能量密度相对较低。
- 工作原理：通过锂离子在正负极之间的嵌入和脱嵌实现充放电。充电时锂离子从正极脱嵌，经电解质嵌入负极；放电时相反。
- 所属类别：锂离子电池
