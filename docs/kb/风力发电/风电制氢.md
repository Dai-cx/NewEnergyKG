# 风电制氢

## 概述与原理
- 技术描述：风电制氢是一种利用风力发电电解水生产绿氢的技术。将波动性强的风电与电解槽结合，通过灵活调节电解负荷实现风电就地消纳，产出零碳绿氢。是风电消纳、绿氢生产和深度脱碳的重要技术路径。
- 工作原理：风力发电机发出交流电，经变流器转换为直流电供给电解槽。电解槽中的水在电流作用下分解为氢气和氧气（2H2O→2H2+O2）。氢气经纯化、压缩后储存，可用于燃料电池发电、化工原料或交通燃料。
- 所属类别：风力发电
