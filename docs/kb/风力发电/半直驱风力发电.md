# 半直驱风力发电

## 概述与原理
- 技术描述：半直驱（中速永磁）风力发电技术采用中速永磁同步发电机（转速约100-300rpm），通过一级或两级齿轮箱适度增速，兼顾了双馈技术的成本优势和直驱技术的可靠性优势。近年来在海上风电中应用快速增长。
- 工作原理：风力推动叶片旋转，经一级或两级中速齿轮箱（增速比约10-30）驱动中速永磁同步发电机。发电机通过全功率变流器实现并网，永磁体提供励磁，无需电刷和滑环。
- 所属类别：风力发电
