# 海上漂浮式风电

## 概述与原理
- 技术描述：海上漂浮式风电是一种将风力发电机组安装在漂浮式平台上的海上风电技术，适用于水深超过60米的深远海区域。通过系泊系统锚固于海底，平台可随风浪轻微运动。深远海风资源更丰富稳定，漂浮式风电是海上风电向深海拓展的必然选择。
- 工作原理：风机安装在半潜式、 Spar 或张力腿式（TLP）漂浮平台上，平台通过系泊链/缆锚固于海底。风机捕获风能发电，电力经动态电缆传输至海底电缆。平台设计需平衡风机重量、浮力、稳性和运动响应。
- 所属类别：风力发电
