# 分散式风电

## 概述与原理
- 技术描述：分散式风电是指位于用电负荷中心附近，接入配电网（35kV及以下电压等级）就近消纳的小型风电项目。单个项目容量通常在几兆瓦至几十兆瓦，具有就地开发、就近接入、灵活部署等特点，是风电与负荷中心协同发展的重要模式。
- 工作原理：在负荷中心附近（工业园区、农村、城镇周边）安装中小型风力发电机组，所发电力优先供给本地负荷，多余电量上网，不足部分由电网补充。通常采用低风速机型和智能控制技术，适应复杂地形和风况。
- 所属类别：风力发电
