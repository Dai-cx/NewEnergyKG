# 双馈风力发电

## 概述与原理
- 技术描述：双馈风力发电技术采用双馈感应发电机（DFIG），通过部分功率变流器连接转子绕组，实现变速恒频运行。双馈机组约占全球风电装机量的50%以上，技术成熟、成本较低，是陆上风电的主流技术路线之一。
- 工作原理：风力推动叶片旋转，经齿轮箱增速后驱动双馈感应发电机转子。转子绕组通过滑环和碳刷连接部分功率变流器（约30%额定功率），通过调节转子电流频率实现变速运行下的恒频输出。
- 所属类别：风力发电
