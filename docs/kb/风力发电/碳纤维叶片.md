# 碳纤维叶片

## 概述与原理
- 技术描述：碳纤维叶片是一种以碳纤维复合材料为主要结构材料的风力发电机叶片。与传统玻璃纤维叶片相比，碳纤维叶片具有更高的比强度、比刚度和疲劳性能，可实现更长、更轻、更高效的叶片设计，是大型化风机（5MW+）的关键技术。
- 工作原理：利用碳纤维的高强度、高模量特性替代传统玻璃纤维，在保证叶片结构强度的前提下大幅减轻重量。碳纤维预浸料经铺层、真空灌注、固化等工艺制成主梁帽、腹板等关键承力结构，与玻璃纤维蒙皮组合形成完整叶片。
- 所属类别：风力发电
