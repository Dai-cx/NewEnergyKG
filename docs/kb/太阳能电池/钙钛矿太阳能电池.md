# 钙钛矿太阳能电池

## 概述与原理
- 技术描述：钙钛矿太阳能电池是利用钙钛矿型有机金属卤化物半导体作为吸光材料的太阳能电池。具有转换效率高、成本低、可柔性制备等优势，被视为下一代光伏技术。
- 工作原理：钙钛矿材料吸收光子后产生电子-空穴对，在内建电场作用下分离并分别被电子传输层和空穴传输层收集，形成光生电流。
