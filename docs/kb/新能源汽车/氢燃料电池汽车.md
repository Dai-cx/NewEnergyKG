# 氢燃料电池汽车

## 概述与原理
- 技术描述：氢燃料电池汽车（FCEV）是一种以氢气为燃料、通过质子交换膜燃料电池将化学能转化为电能驱动电动机的汽车。具有加氢速度快（3-5分钟）、续航里程长（500-800km）、零排放（仅排放水）等优势，是重型商用车和长途运输的重要技术路线。
- 工作原理：车载高压储氢罐（35MPa或70MPa）储存氢气，氢气经减压阀供给燃料电池电堆。在电堆中氢气在阳极被氧化为质子和电子，质子通过质子交换膜迁移至阴极与氧气和电子结合生成水，电子经外电路驱动电机。
- 所属类别：新能源汽车
