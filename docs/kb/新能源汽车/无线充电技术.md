# 无线充电技术

## 概述与原理
- 技术描述：电动汽车无线充电技术是一种通过电磁感应或磁共振原理，无需物理连接即可实现电能传输的充电方式。车辆停放在充电板上即可自动充电，具有便利性高、无插拔磨损、可集成到道路/停车场等优势。目前功率已达11-300kW，主要用于私家车、公交和自动驾驶车辆。
- 工作原理：基于电磁感应或磁共振耦合原理。发射线圈（埋于地面）通入高频交流电产生交变磁场，接收线圈（安装于车辆底部）感应磁场产生感应电流，经整流滤波后给电池充电。磁共振方式通过调谐发射和接收线圈频率实现中距离高效传输。
- 所属类别：新能源汽车
