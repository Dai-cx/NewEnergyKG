# CTC电池底盘一体化

## 概述与原理
- 技术描述：CTC（Cell to Chassis）电池底盘一体化技术是一种将电池电芯直接集成到底盘结构中，取消传统电池包上盖和模组，使电池成为底盘结构一部分的先进集成技术。相比传统CTP技术，CTC可进一步减少零部件数量、降低重量、提升空间利用率和整车刚度。特斯拉、比亚迪、零跑等品牌已量产CTC车型。
- 工作原理：将电池电芯直接排列在底盘框架内，电芯本身作为底盘结构件参与受力。取消传统电池包的模组、侧板、上盖等结构，用底盘地板替代电池包上盖，用底盘纵梁和横梁替代电池包边框。电芯通过结构胶与底盘粘接，形成一体化承载结构。
- 所属类别：新能源汽车
