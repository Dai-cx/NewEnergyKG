# 固态电池装车

## 概述与原理
- 技术描述：固态电池装车是指将固态电解质电池应用于新能源汽车的技术。与传统液态电解质锂电池相比，固态电池使用固态电解质替代液态电解液和隔膜，具有能量密度更高（可达400-500Wh/kg）、安全性更好（无热失控风险）、工作温度范围更宽等优势。目前半固态电池已开始装车，全固态电池预计2027-2030年量产。
- 工作原理：使用固态电解质（氧化物、硫化物或聚合物）替代传统液态电解液和隔膜。锂离子在固态电解质晶格中迁移，在正负极之间往返实现充放电。固态电解质不可燃，从根本上消除了热失控风险。可匹配高电压正极（如高镍）和锂金属负极，大幅提升能量密度。
- 所属类别：新能源汽车
