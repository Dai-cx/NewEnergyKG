# 插电式混合动力汽车

## 概述与原理
- 技术描述：插电式混合动力汽车（PHEV）是一种同时搭载内燃机和电动机两套动力系统的汽车，可通过外部充电和燃油两种方式补能。电池容量较普通混动更大，支持纯电行驶50-200km，满足日常通勤纯电需求，长途行驶切换混动模式，兼顾环保和续航。
- 工作原理：车辆配备动力电池和内燃机两套动力系统。短途纯电行驶时，电池供电驱动电机；电量不足或高速行驶时，内燃机启动直接驱动车轮或带动发电机发电。两套系统可单独或协同工作，通过动力耦合装置（离合器/行星齿轮）智能分配动力。
- 所属类别：新能源汽车
