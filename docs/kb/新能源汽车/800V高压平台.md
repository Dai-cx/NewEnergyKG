# 800V高压平台

## 概述与原理
- 技术描述：800V高压平台是一种将电动汽车电气系统电压从传统的400V提升至800V的技术架构。通过提高电压降低电流，减少线束截面积和重量，降低电阻损耗，实现更快的充电速度（10-15分钟充至80%）和更高的电机功率密度。保时捷Taycan、比亚迪、小鹏、理想等品牌已推出800V车型。
- 工作原理：根据功率公式P=UI，在功率不变时提高电压可降低电流。根据焦耳定律Q=I²Rt，降低电流可大幅减少线缆和元器件的发热损耗。800V平台需使用耐高压的碳化硅（SiC）功率器件、高压继电器、高压电缆和耐高压电池包，同时充电桩需支持800V输出。
- 所属类别：新能源汽车
