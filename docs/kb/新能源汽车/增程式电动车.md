# 增程式电动车

## 概述与原理
- 技术描述：增程式电动车（EREV）是一种以电动机为唯一驱动源、搭载小型内燃机作为增程器（仅用于发电）的电动汽车。电池电量充足时纯电行驶，电量不足时增程器启动发电供给电机或给电池充电。理想汽车是该技术路线的代表企业。
- 工作原理：车辆始终由电动机驱动。电池电量充足时，电池直接供电驱动电机。当电池电量降至设定阈值，增程器（小型内燃机+发电机）启动，内燃机以最佳效率转速运行带动发电机发电，电能直接供给电机驱动车辆，多余电量给电池充电。
- 所属类别：新能源汽车

## 优缺点与效率
- 优点：无续航焦虑
- 优点：驾驶体验接近纯电（无变速箱顿挫）
- 优点：增程器始终运行在最佳效率区间
- 优点：城市通勤可纯电行驶
- 优点：结构比插混简单
- 优点：享受新能源牌照政策
- 优点：NVH表现优于插混
- 缺点：能量转换环节多（油→电→机械能），高速油耗偏高
- 缺点：增程器增加重量
- 缺点：增程器噪音和振动
- 缺点：技术路线存在争议
- 缺点：亏电时动力下降
- 缺点：保养需兼顾发动机和电机
- 缺点：后备箱空间受限
- 效率：纯电模式能耗约15-20kWh/100km，增程模式油耗约5-8L/100km
- 成熟度：成熟
- 发展阶段：大规模量产
