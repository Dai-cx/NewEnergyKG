# 纯电动汽车

## 概述与原理
- 技术描述：纯电动汽车（BEV）是一种完全依靠动力电池和电动机驱动的汽车，不搭载内燃机，实现零尾气排放。通过外部电网充电补能，是新能源汽车中技术最成熟、市场占比最高的类型。2024年中国纯电动汽车销量占新能源汽车总销量的约60%。
- 工作原理：动力电池组储存电能，通过电池管理系统（BMS）控制充放电，经高压配电单元将直流电供给电机控制器，电机控制器驱动永磁同步电机或异步电机旋转，经减速器将动力传递至车轮。制动时电机反转实现能量回收。
- 所属类别：新能源汽车
