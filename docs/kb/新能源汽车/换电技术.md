# 换电技术

## 概述与原理
- 技术描述：换电技术是一种通过机械装置在几分钟内将电动汽车耗尽电量的电池包更换为满电电池包的补能方式。用户无需等待充电，换电站集中对电池进行慢充和保养，可延长电池寿命。蔚来、奥动、宁德时代（EVOGO）等企业已在中国建设超过3000座换电站，是新能源汽车补能体系的重要补充。
- 工作原理：换电站内储存多块充满电的标准化电池包。车辆驶入换电工位后，机械臂或举升装置将车辆底部 depleted 电池包卸下，换上满电电池包，整个过程约3-5分钟。换下的电池在站内进行慢充（保护电池）和维护检测。
- 所属类别：新能源汽车
