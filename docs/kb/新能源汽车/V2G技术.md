# V2G技术

## 概述与原理
- 技术描述：车网互动（V2G，Vehicle-to-Grid）技术是一种允许电动汽车与电网进行双向能量交换的技术。车辆不仅从电网充电，还可在电网负荷高峰时将电池电能反向输送给电网，实现削峰填谷、调频调压等功能。V2G将电动汽车从单纯的用电负荷转变为分布式储能单元，是构建新型电力系统的重要技术。
- 工作原理：通过双向充电桩或双向车载充电机（OBC），实现直流电的双向流动。充电时电网→车辆，放电时车辆→电网。车辆BMS与电网调度系统通信，根据电网需求自动调节充放电功率和时机。聚合商将大量车辆的储能能力聚合，参与电力市场交易。
- 所属类别：新能源汽车
