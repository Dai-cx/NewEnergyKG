# 锌溴液流电池

## 概述与原理
- 技术描述：锌溴液流电池是一种以锌和溴为活性物质的液流电池技术。充电时锌沉积在负极，溴在正极生成；放电时锌溶解，溴被还原。具有能量密度较高、成本低、安全性好等特点，但存在溴的腐蚀性和自放电问题。
- 工作原理：充电时，负极电解液中的Zn2+被还原为金属锌沉积在电极上；正极电解液中的Br-被氧化为Br2（以络合物形式存在）。放电时反应逆向进行，锌溶解，溴被还原。
- 所属类别：电化学储能
