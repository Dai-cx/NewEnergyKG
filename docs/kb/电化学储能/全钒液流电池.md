# 全钒液流电池

## 概述与原理
- 技术描述：全钒液流电池（VRFB）是一种以钒离子不同价态为活性物质的大型电化学储能系统。电解液储存在外部储罐中，通过泵送循环流经电堆发生氧化还原反应实现充放电。具有安全性极高、循环寿命超长、容量与功率可独立设计等优势，是长时储能的主流技术路线之一。
- 工作原理：充电时，正极电解液中的V4+被氧化为V5+，负极电解液中的V3+被还原为V2+；放电时反应逆向进行。电解液分别储存在正负极储罐中，通过循环泵流经离子交换膜分隔的电堆。
- 所属类别：电化学储能
