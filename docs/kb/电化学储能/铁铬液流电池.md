# 铁铬液流电池

## 概述与原理
- 技术描述：铁铬液流电池是一种以铁离子（Fe2+/Fe3+）和铬离子（Cr2+/Cr3+）为活性物质的液流电池储能技术。与全钒液流电池相比，铁铬体系原材料成本更低、资源更丰富，但存在析氢副反应和交叉污染等技术挑战，是目前液流电池领域的重要研究方向。
- 工作原理：正极电解液中的Fe2+在充电时被氧化为Fe3+，负极电解液中的Cr3+被还原为Cr2+；放电时反应逆向进行。电解液通过电堆循环，在离子交换膜两侧发生氧化还原反应。
- 所属类别：电化学储能
