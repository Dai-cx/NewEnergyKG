# 钠离子电池

## 概述与原理
- 技术描述：钠离子电池是使用钠离子作为电荷载体的新型二次电池技术。由于钠元素在地壳中储量丰富、分布广泛，成本远低于锂，且安全性好、低温性能优异，被视为锂离子电池的重要替代方案，尤其适用于储能和低速电动车领域。
- 工作原理：充放电过程中，钠离子在正负极材料之间嵌入和脱出。充电时钠离子从正极脱嵌，经电解液嵌入负极；放电时相反。与锂离子电池原理类似，但使用钠盐电解液和适配钠离子半径的电极材料。
- 所属类别：电化学储能

- 优点：钠资源丰富，成本仅为锂的1/30
- 优点：安全性好，热稳定性高
- 优点：低温性能优异（-20℃保持80%+容量）
- 优点：可快充（10分钟充至80%）
- 优点：无过放电顾虑
- 优点：与锂电池产线兼容度高
- 缺点：能量密度较低（100-160Wh/kg）
- 缺点：循环寿命待提升（目前3000-6000次）
- 缺点：产业链不成熟，规模化不足
- 缺点：正极材料电压平台较低
- 缺点：负极硬碳成本较高
- 缺点：能量密度天花板低于锂电
- 效率：能量密度100-160Wh/kg，充放电效率约95%
