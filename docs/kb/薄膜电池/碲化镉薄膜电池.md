# 碲化镉薄膜电池

## 概述与原理
- 技术描述：碲化镉（CdTe）薄膜电池是一种以碲化镉为吸光材料的薄膜太阳能电池。CdTe具有接近理想的光学带隙（1.5eV）和很高的光吸收系数，是商业化最成功的薄膜电池技术，主要用于建筑一体化和分布式场景。
- 工作原理：太阳光穿过透明导电玻璃和N型CdS窗口层，被P型CdTe吸收层吸收产生电子-空穴对。载流子在CdS/CdTe异质结内建电场作用下分离，电子流向CdS层，空穴流向背电极。
- 所属类别：薄膜电池
