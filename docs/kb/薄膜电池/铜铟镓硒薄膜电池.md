# 铜铟镓硒薄膜电池

## 概述与原理
- 技术描述：铜铟镓硒（CIGS）薄膜电池是一种以铜铟镓硒为吸光材料的多晶薄膜太阳能电池。CIGS具有可调的带隙（1.0-1.7eV）和极高的光吸收系数，实验室效率是所有薄膜电池中最高的，且可柔性制备。
- 工作原理：太阳光穿过透明导电层和N型硫化镉缓冲层，被P型CIGS吸收层吸收。CIGS中的铜、铟、镓比例可调，优化带隙匹配太阳光谱。载流子在异质结处分离并被电极收集。
- 所属类别：薄膜电池
