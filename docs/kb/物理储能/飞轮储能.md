# 飞轮储能

## 概述与原理
- 技术描述：飞轮储能是一种利用高速旋转飞轮的动能存储电能的物理储能技术。通过电动机带动飞轮加速旋转将电能转化为机械能储存，需要放电时飞轮带动发电机减速旋转将机械能转化为电能输出。具有响应极快、循环寿命无限、效率高等特点，适用于电能质量调节和不间断电源。
- 工作原理：基于角动量守恒定律，高速旋转的飞轮储存动能E=1/2*I*w^2。充电时电机作为电动机驱动飞轮加速；放电时电机作为发电机，飞轮减速释放能量。采用磁悬浮轴承和真空环境消除摩擦损耗。
