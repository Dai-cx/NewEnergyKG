# 压缩空气储能

## 概述与原理
- 技术描述：压缩空气储能（CAES）是一种利用电能将空气压缩并储存在地下洞穴、盐穴或人造储气罐中，在需要时释放高压空气驱动透平发电的大规模物理储能技术。分为传统补燃式和先进绝热式两种路线，具有规模大、寿命长、环境友好等特点。
- 工作原理：用电低谷期，利用电动机驱动压缩机将空气压缩至高压（约70-100bar），储存于地下盐穴或储气罐。用电高峰期，释放高压空气，经换热器预热后驱动透平膨胀机带动发电机发电。先进绝热式（AA-CAES）将压缩热储存并回收，无需补燃。
- 所属类别：物理储能
