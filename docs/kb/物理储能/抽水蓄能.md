# 抽水蓄能

## 概述与原理
- 技术描述：抽水蓄能是目前技术最成熟、应用最广泛的大规模储能技术。利用电力系统负荷低谷时的多余电能，将水从下游水库抽到上游水库储存；在负荷高峰期释放上库水流驱动水轮发电机组发电。具有储能容量大、循环寿命长、技术成熟可靠等优势，是电网调峰调频的压舱石。
- 工作原理：储能时，电动机驱动水泵将水从下水库抽至上水库，电能转化为水的重力势能。释能时，上水库的水经压力管道流下，驱动水轮机旋转带动发电机发电。可逆式水泵水轮机可实现抽水和发电双向运行。
- 所属类别：物理储能
