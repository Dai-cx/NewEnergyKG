# 重力储能

## 概述与原理
- 技术描述：重力储能是一种利用重物升降实现势能存储和释放的新型物理储能技术。通过电动机提升重物（混凝土块、砂石等）至高处储存电能，放电时重物下落驱动发电机发电。具有环境友好、选址灵活、循环寿命长等优势，是近年来新兴的储能技术路线。
- 工作原理：储能阶段，利用低谷电驱动电机通过卷扬机/起重机将重物提升至高处，电能转化为重力势能（E=mgh）。放电阶段，重物在重力作用下下落，带动发电机旋转发电。
- 所属类别：物理储能
