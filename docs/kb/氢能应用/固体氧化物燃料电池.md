# 固体氧化物燃料电池

## 概述与原理
- 技术描述：固体氧化物燃料电池（SOFC）是一种在高温（600-1000℃）下运行的燃料电池，使用固体氧化物陶瓷作为电解质。SOFC具有极高的发电效率（可达60%），且可使用多种燃料（氢气、天然气、沼气、煤制气），余热可利用，适合分布式发电和热电联供。
- 工作原理：氢气或碳氢燃料在阳极被氧化生成电子和氧离子（H₂+O²⁻→H₂O+2e⁻）。氧离子通过固体氧化物电解质（YSZ）迁移至阴极，与氧气结合生成氧离子（1/2O₂+2e⁻→O²⁻）。高温下氧离子传导率高，反应动力学快。
- 所属类别：氢能应用
