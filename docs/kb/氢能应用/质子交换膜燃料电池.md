# 质子交换膜燃料电池

## 概述与原理
- 技术描述：质子交换膜燃料电池（PEMFC）是一种以氢气为燃料、空气为氧化剂的低温燃料电池。氢气在阳极被氧化为质子和电子，质子通过质子交换膜迁移至阴极与氧气和电子结合生成水。PEMFC具有启动快、效率高、功率密度大等优势，是氢燃料电池汽车的主流技术。
- 工作原理：氢气在阳极催化剂作用下分解为质子和电子（H₂→2H⁺+2e⁻）。质子通过质子交换膜迁移至阴极，电子经外电路做功后到达阴极。在阴极，质子、电子和氧气结合生成水（1/2O₂+2H⁺+2e⁻→H₂O）。
- 所属类别：氢能应用
