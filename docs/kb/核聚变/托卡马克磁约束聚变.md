# 托卡马克磁约束聚变

## 概述与原理
- 技术描述：托卡马克（Tokamak）是一种利用强磁场约束高温等离子体实现可控核聚变的装置。通过环形磁场将氘氚等离子体加热至1亿℃以上，使其发生聚变反应释放巨大能量。托卡马克是目前最接近实现可控核聚变的技术路线，国际热核聚变实验堆（ITER）和中国环流器（HL-2M/EAST）是代表性装置。
- 工作原理：在环形真空室中，利用超导磁体产生强环形磁场和极向磁场，将氘氚等离子体约束在磁笼中。通过中性束注入、射频波和欧姆加热将等离子体加热至1亿℃以上，氘和氚原子核克服库仑斥力发生聚变（D+T→He+n+17.6MeV），释放巨大能量。
- 所属类别：核聚变
