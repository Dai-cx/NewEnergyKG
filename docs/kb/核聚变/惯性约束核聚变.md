# 惯性约束核聚变

## 概述与原理
- 技术描述：惯性约束核聚变（ICF）是一种利用高能激光或离子束瞬间加热压缩氘氚燃料靶丸，使其在极短时间内达到高温高密度状态实现聚变的技术。美国国家点火装置（NIF）于2022年首次实现能量净增益（Q>1），是人类可控核聚变的重要里程碑。
- 工作原理：利用192束高能激光（总能量约2MJ）从四面八方同时照射氘氚燃料靶丸，靶丸外层烧蚀产生向内反冲动量，将燃料压缩至极高密度（约铅密度的100倍）和温度（约1亿℃）。在极短时间内（纳秒级），燃料依靠自身惯性维持约束，发生聚变反应。
- 所属类别：核聚变
