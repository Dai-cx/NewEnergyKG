# AP1000

## 概述与原理
- 技术描述：AP1000是美国西屋公司开发的第三代非能动压水堆核电技术，采用非能动安全系统设计理念，利用重力、自然循环、压缩空气等自然力实现安全功能，大幅简化系统、减少设备数量。全球首堆在中国三门核电站建成投运，是中国引进消化吸收再创新的重要三代核电技术。
