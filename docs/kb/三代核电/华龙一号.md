# 华龙一号

## 概述与原理
- 技术描述：华龙一号（HPR1000）是中国具有完全自主知识产权的三代核电技术，由中国核工业集团和中国广核集团联合研发。采用177组燃料组件堆芯、双层安全壳、能动与非能动相结合的安全系统，具有安全性高、经济性好、设备国产化率高等特点，是中国核电走出去的主力机型。
- 工作原理：采用压水堆技术，以低浓缩铀为燃料，通过控制棒调节中子通量维持链式裂变反应。一回路高压水冷却堆芯并带走热量，通过蒸汽发生器将热量传递给二回路产生蒸汽，驱动汽轮发电机发电。双层安全壳和多重安全系统确保极端事故下的安全。
- 所属类别：三代核电
