# BC电池

## 概述与原理
- 技术描述：背接触（BC）电池是一种将电池正面所有金属电极全部转移到背面的高效晶硅太阳能电池技术。正面无栅线遮挡，可最大化受光面积，具有转换效率高、外观美观等优势，适合建筑一体化和分布式应用场景。
- 工作原理：通过激光开槽、离子注入或印刷等技术，将电池正面的发射极和基极全部引到背面，形成交叉排列的指状电极结构。正面仅保留减反射膜和钝化层，无金属栅线遮挡。
- 所属类别：晶硅电池

## 优缺点与效率
- 优点：正面无栅线，受光面积最大化
- 优点：转换效率高（可达26%+）
- 优点：外观美观，适合BIPV
- 优点：低电流设计降低电阻损耗
- 优点：可与TOPCon或HJT技术叠加
- 缺点：工艺复杂，良率较低
- 缺点：设备投资高
- 缺点：背面电极设计复杂
- 缺点：串联电阻控制难度大
- 缺点：与现有产线兼容性差
- 效率：量产约25-26.5%，实验室最高27%
- 成熟度：产业化初期
