# HJT电池

## 概述与原理
- 技术描述：异质结（HJT）电池是一种基于晶体硅和非晶硅薄膜异质结构的高效太阳能电池。具有转换效率高、温度系数低、工艺流程短等优势。
- 工作原理：在N型晶硅衬底两侧沉积本征和掺杂非晶硅薄膜，形成P-i-N异质结，利用非晶硅的优异钝化性能降低表面复合。
- 所属类别：晶硅电池
