# TOPCon电池

- 技术描述：隧穿氧化层钝化接触（TOPCon）电池是一种高效晶硅太阳能电池技术，通过在电池背面引入超薄氧化硅和掺杂多晶硅层，实现优异的钝化效果和载流子选择性接触。
