# PERC电池

## 概述与原理
- 技术描述：发射极钝化和背面接触（PERC）电池是一种高效晶硅太阳能电池技术，通过在电池背面增加钝化层和局部接触结构，减少背面复合，提升开路电压和转换效率。PERC技术工艺成熟，与现有产线兼容性好，是目前市场占有率最高的光伏电池技术。
- 工作原理：在硅片背面沉积氧化铝/氮化硅钝化叠层，利用激光开孔形成局部接触点，减少背面载流子复合，同时增强背面内反射，提高长波吸收效率。
- 所属类别：晶硅电池
