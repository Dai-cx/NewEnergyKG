# IBC电池

## 概述与原理
- 技术描述：叉指式背接触（IBC）电池是BC电池的一种具体实现形式，采用交叉指状排列的P区和N区电极全部位于电池背面。IBC技术可与HJT或TOPCon技术叠加形成HBC或TBC电池，进一步提升效率。
- 工作原理：在N型硅片背面通过扩散或离子注入形成交叉排列的P+区和N+区，配合钝化接触结构，所有正负电极均位于背面。正面采用绒面和减反射膜最大化光吸收。
- 所属类别：晶硅电池
